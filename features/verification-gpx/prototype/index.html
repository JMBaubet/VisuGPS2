Synthèse —
Clé Mapbox requise
Renseignez une clé API Mapbox dans le panneau de gauche (section « Clés API › Mapbox ») pour afficher le fond de carte. La trace, l'analyse et les corrections restent pleinement fonctionnelles.
Anomalie
La zone sélectionnée sera remplacée par le tracé routier entre les points Début et Fin (conservés). Points proposés par défaut : ancres de l'anomalie (routes droites encadrant la boucle, ou contexte sain). Extension possible de ±3 points, sans mordre sur les anomalies voisines. Une zone plus courte = réponse plus rapide.
Routage proposé — choisissez le tracé à retenir :
Aperçu : les points grisés seront supprimés, les points bleus seront conservés ; la ligne bleue montre le raccord direct entre les points conservés. Un point isolé est possible en amenant Début sur Fin. Plage limitée à l'emprise de l'anomalie.
Cette anomalie est marquée faux positif : elle sera laissée telle quelle dans le GPX généré.

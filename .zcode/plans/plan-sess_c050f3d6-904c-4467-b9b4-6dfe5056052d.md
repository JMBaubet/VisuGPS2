## Plan — Virage de cap : rectangle coloré entre ticks + tableau à la demande

### Décisions validées
- **Timeline** : un **rectangle coloré entre deux ticks RdV consécutifs** (les ticks bleus restent inchangés).
- **Sens** : **teal = horaire** (↻), **deep-purple = anti-horaire** (↺).
- **Intensité** : jeu sur la clarté Material Design (lighten → darken) — **clair = virage faible, foncé = virage fort**.
- **Portée** : seuls les **segments « brutaux »** (taux ≥ seuil réglable) ont un rectangle ; la clarté code à quel point le taux dépasse le seuil.
- **Critère** : taux = `|Δcap| / Δdist` en **°/km**, seuil par défaut **150**, bornes **10–1000**, pas **10** (filtre d'affichage, pas de régénération des keyframes).
- Signe : `bearingDelta(a,b) ≥ 0` = horaire, `< 0` = anti-horaire.

### Fichiers

**1. `src/algorithms/headingChanges.ts` (NOUVEAU, module pur)**
- `export type RotationDirection = 'horaire' | 'anti-horaire'`.
- `export interface HeadingChange { fromIndex, fromDistanceM, toDistanceM, distM, deltaDeg, rateDegPerKm, direction }`.
- `export function computeHeadingChanges(keyframes: Keyframe[]): HeadingChange[]` (delta via `bearingDelta`, skip si `distM ≤ 0`).
- `export function headingChangeColor(direction, rate, threshold): string` — mappe `ratio = rate/threshold` sur les nuances MD : `lighten-3` (<1.5), `lighten-1` (<2), `base` (<3), `darken-2` (<5), `darken-4` (≥5). Hex codés en dur : **teal** `#E0F2F1→#004D40`, **deep-purple** `#EDE7F6→#311B92`.
- `export const ROTATION_BASE_COLORS = { horaire: '#009688', 'anti-horaire': '#673AB7' }` (pour le tableau).

**2. `src/stores/edition.ts`**
- `headingChangeThresholdDegPerKm = ref(150)` + `setHeadingChangeThreshold(m)` (clamp [10,1000], pas 10 — pas de régénération).
- `showHeadingChangesPanel = ref(false)` + `toggleHeadingChangesPanel()`.
- `headingChanges` (tous) et `brutalHeadingChanges` (filtrés `rateDegPerKm ≥ seuil`).
- Exports.

**3. `src/components/Edition/ProgressGraph.vue`**
- `headingChangeRects` computed depuis `brutalHeadingChanges` : pour chaque virage brutal, un `<rect>` **entre le tick `i` et le tick `i+1`** (`x = fromDistanceM·PX_PER_METER + RDV_WIDTH/2`, `width = Δdist·PX_PER_METER − RDV_WIDTH`), bande de **4 px** ancrée au bas de la zone RdV (`y = rdvZoneY + rdvZoneHeight − 4`), `fill = headingChangeColor(...)`.
- `<title>` (tooltip SVG) : « Δcap +87° · 300 m · 180°/km (horaire) ».
- Les ticks RdV bleus ne changent **pas**.

**4. `src/components/Edition/HeadingChangesPanel.vue` (NOUVEAU)**
- Overlay non modal (carte wrapper), `top:12px; left:12px; z-index:6`, fond `rgba(0,0,0,0.8)`, `pointer-events:auto`. `v-if="showHeadingChangesPanel && hasKeyframes"`.
- Légende : ● teal = horaire · ● deep-purple = anti-horaire + compteur.
- `v-table` `density="compact"` : `#` / `Départ (km)` / `Arrivée (km)` / `Δ dist` / `Δ cap` (signé) / `Taux (°/km)` / `Sens` (↻ teal / ↺ deep-purple).
- Clic sur une ligne → `seekToDistance(fromDistanceM)` + `selectKeyframe(fromDistanceM)`.

**5. `src/components/Edition/EditionToolbar.vue`**
- Champ « Seuil cap (°/km) » (comme « Gap min ») → `setHeadingChangeThreshold`.
- Bouton bascule « Cap brutaux » (icône `mdi-rotate-3d`) avec badge du nombre `brutalHeadingChanges.length` → `toggleHeadingChangesPanel()`.

**6. `src/views/EditionCamera.vue`** : monter `<HeadingChangesPanel />` dans `.edition-map-wrapper` (après `CameraEditor`).

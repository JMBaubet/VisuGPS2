## Plan — Deux fichiers keyframes par trace (16:9 / 4:3)

### Décisions validées
- **Nommage explicite** : 16:9 → `keyframes/{trace_id}_169.json`, 4:3 → `keyframes/{trace_id}_43.json`. Les anciens fichiers `{trace_id}.json` ne sont plus lus (régénérés au 1ᵉʳ chargement) ; nettoyage du fichier hérité à la suppression d'une trace.
- **Les deux dès l'ouverture** : chargement/génération du ratio actif (16:9 par défaut) **et** génération de l'autre ratio en arrière-plan s'il n'existe pas.
- **Viewports de référence** : 16:9 → `1920×1080`, 4:3 → `1440×1080` (même hauteur → pose caméra et occlusions identiques, seul le champ horizontal change, exactement le paramètre du ratio).
- **Par défaut** : `showViewportFrame = true` (16:9 affiché), `viewportAspect = '16:9'`.

### Fichiers
1. `src/algorithms/keyframeGenerator.ts` — exporter `ViewportAspect` + `VIEWPORTS_BY_ASPECT` (1920×1080 / 1440×1080) ; nouveau paramètre `viewport` en fin de `generateKeyframes`, transmis à frustum et stocké dans le JSON (simple + frustum).
2. `src-tauri/src/import_gpx.rs` — `get_keyframes_path(mode_dir, trace_id, viewport_aspect)` via `keyframes_file_name` (`_169` / `_43`, fallback non suffixé) ; les 3 commandes acceptent `viewport_aspect` ; `delete_trace` supprime les fichiers `_169`, `_43` et l'ancien non suffixé.
3. `src/stores/keyframes.ts` — `loadKeyframes(traceId, viewportAspect)` ; `saveKeyframes(set)` dérive le ratio de `set.viewport` (pas de changement d'appelants) ; `clearKeyframes(traceId, viewportAspect)`.
4. `src/stores/edition.ts` — `viewportAspect` ('16:9' défaut), `setViewportAspect` (reset sélection + affiche le cadre), `showViewportFrame = ref(true)` ; exports.
5. `src/components/Edition/EditionMap.vue` — `generateKeyframesFor(aspect)` (génère+sauvegarde, `aspectsPendingTerrain`) ; `ensureAspectKeyframes(aspect, {active, force?})` (charge sinon génère, store seulement si actif) ; initial : actif puis l'autre en arrière-plan ; watcher `viewportAspect` (charge/génère les deux) ; watcher `[algo, gap]` (régénère les deux, `force`) ; régénération terrain des ratios en attente ; viewport par ratio passé à `generateKeyframes`.
6. `src/components/Edition/EditionToolbar.vue` — bouton ViewPort → `v-menu` (16:9, 4:3 avec checkmark, séparateur, Afficher/Masquer).
7. `src/components/Edition/ViewportFrame.vue` — `targetRatio` et label calculés depuis le ratio du store.
8. Docs — `ARCHITECTURE.md`, `CONTEXT.md`, `DATA_STORAGE.md` (lignes 36/46/122-131/155), `ROADMAP_EDITION_CAMERA.md`.
